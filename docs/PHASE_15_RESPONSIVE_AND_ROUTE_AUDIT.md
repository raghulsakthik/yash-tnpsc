## 2. Keep the standalone Next.js routes

The earlier roadmap called the page routes under `src/app` orphaned. The current code audit shows they are still deep-link targets generated by backend flows:
- `/api/curriculum/active` emits `/lesson/:topic`, `/practice/:topic`, `/pyqs/:topic`, `/tests/weekly`, `/revision`, and `/journey` action URLs.
- Course API responses emit `/lesson/:topic` links.
- Notification/action URLs can point learners directly to lesson pages.

Decision: **do not delete the Next.js learner routes.** They are useful deep-link and standalone route surfaces even though the primary dashboard shell is the nova-ui SPA. Removing them would break server-generated navigation and notification links. Future consolidation should route deep links into the SPA only after preserving query parameters, authentication, and browser history behavior.
